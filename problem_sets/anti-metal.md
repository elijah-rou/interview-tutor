# anti-metal interview set

The checked-in v2 problem-set schema represents ordered membership but not per-member notes. These are the selection rationales for the shipped `anti-metal` set:

1. **Time Based Key-Value Store (981):** Temporal state and point-in-time reads.
2. **LRU Cache (146):** Stateful API design and data-structure invariants.
3. **Course Schedule (207):** Resource dependencies, cycles, topological sorting.
4. **Merge Intervals (56):** Trace, deployment, and incident time windows.
5. **Top K Frequent Elements (347):** Telemetry aggregation and heavy hitters.
6. **Longest Substring Without Repeating Characters (3):** Sliding-window and hash-map baseline.
7. **Number of Islands (200):** Graph traversal and visited-state handling.
8. **Binary Tree Level Order Traversal (102):** Tree BFS and queue boundaries.
9. **Kth Largest Element in a Stream (703):** Streaming computation with bounded memory.
10. **Coin Change (322):** Standard bottom-up dynamic programming.
